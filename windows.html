Run dialog vs. the shells

The Run dialog (Win+R) launches a program or opens a location instantly — perfect for one-liners like regedit, services.msc or shell:startup. The Command Prompt (CMD) and PowerShell are full shells where you run sequences of commands, pipe output and script tasks. Many Run entries also work as commands inside either shell. Press Win+X (or right-click Start) for quick access to both shells and admin tools.

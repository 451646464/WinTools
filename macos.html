Opening Terminal on a Mac

Press ⌘ + Space to open Spotlight, type Terminal and press Enter. You can also find it under Applications → Utilities → Terminal. Most commands here use the default zsh shell (macOS Catalina and later). To install extra tools, first install Homebrew with the command shown in the “Packages & Apps” category, then use brew install for anything you need.

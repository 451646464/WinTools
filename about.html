About the project

Built to make the terminal approachable.

WinTools is a free, static reference that explains the commands and tools of Linux, Windows, macOS, Cisco networking and server administration in plain language — with every option and a working example, so you can learn by doing.

What it is

A hand-curated, searchable library of the most useful commands and built-in tools for five platforms — the three major desktop operating systems plus Cisco IOS and server administration — grouped by category and written for humans.

How it works

A plain static site — HTML, CSS and JavaScript only. No framework, no build step, no backend and no analytics. It loads fast, works offline and respects your privacy.

Why it exists

Command references are often terse or incomplete. WinTools pairs a clean syntax line with a full option breakdown and real examples, so a beginner and a pro both get value.

Coverage & scope

What is included

Each platform page is grouped into clear categories so you can scan or search.

Linux & Kali

Files & directories · Text & search · System & processes · Networking · Packages (apt, dnf, pacman) · Disk & filesystems · Permissions & users · Archives · Kali security tools (nmap, hydra, john, hashcat, sqlmap, Metasploit, aircrack-ng, and more).

Windows

Run dialog (Win+R) shortcuts · Command Prompt (CMD) · PowerShell cmdlets · Networking (ipconfig, netstat, netsh) · Files & disk (chkdsk, diskpart, robocopy, sfc, DISM) · System & troubleshooting · Admin & services.

macOS

Files & directories · Text & search · System & processes · Networking · Packages & apps (Homebrew, mas, softwareupdate) · macOS-specific (defaults, screencapture, Disk Utility, Time Machine) · Developer (git, Xcode tools).

Cisco Networking

Modes & navigation (EXEC, global config) · Show / verify (running-config, ip int brief, version, route, CDP, MAC table) · Interfaces · VLANs & trunking (VTP, EtherChannel) · Routing (static, OSPF, EIGRP, RIP) · ACLs (standard, extended, named) · Device security (port-security, banners) · NAT & DHCP · Troubleshooting (ping, traceroute, debug).

Server Admin

Web servers (Nginx, Apache, certbot/TLS) · Databases (MySQL, PostgreSQL, pg_dump) · Windows Server roles (Active Directory, DNS, DHCP, IIS) · Containers (Docker, docker compose) · Services & scheduling (systemd, cron, timers) · Monitoring & logs (top, df, journalctl, ss) · Backup (rsync, tar, mysqldump, verification).

⚠ Safety notice

Some commands can permanently delete data, overwrite disks or change how a system behaves — for example rm -rf, mkfs and dd on Linux/macOS, or diskpart, format and clean on Windows. Security tools such as nmap, hydra and sqlmap are intended for systems you own or are explicitly authorised to test.

Always read the full option list before running a command, prefer a non-destructive flag first, back up important data, and practise in a virtual machine or on test data when you are learning. The examples here are for education — you are responsible for how you use them.

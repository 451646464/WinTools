The four IOS modes

Cisco IOS is hierarchical. You start in user EXEC (Router>), type enable to reach privileged EXEC (Router#) where all show and diagnostic commands live, then configure terminal to enter global configuration ((config)#) for changes. From there, interface … or line … drops you into a specific sub-mode. Type ? at any point to see what is available, end to jump back to #, and write memory to save your work before it is lost on reload.

New to the terminal?

A command is made of the program name plus options and arguments, for example ls -la /var/log. Here ls is the program, -la are options (long format + all files) and /var/log is the target path. Options starting with a single dash are short flags; those with a double dash (e.g. --max-depth) are long flags. Run man COMMAND or COMMAND --help on your system for the official manual.

A note on running as root / Administrator

Most server commands that change state need elevated privileges — on Linux/macOS prefix them with sudo, and on Windows Server run PowerShell as Administrator. On a real server, prefer a dedicated service account over a full root/admin login, keep services under systemd or a process manager rather than a bare shell, and always test a restore path before you rely on a backup. Validate config changes (for example nginx -t or apache2ctl configtest) before reloading a production service.
